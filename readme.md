
# EX01_MONDRIAN: Parte B
Para resolver a parte B do exercício, decidi adicionar uma certa instabilidade à linha horizontal que separa a zona vermelha. A linha desloca-se ligeiramente para cima ou para baixo. A cada 90 frames, o `random()` escolhe uma nova posição dentro de um limite de 10 píxeis em cada direção. O movimento é feito de forma suave para que a linha não salte de forma brusca. Assim, a composição mantém a sua estrutura, mas ganha uma pequena instabilidade que contrasta com a geometria rígida de Mondrian.
